# нитка

Витрина магазина одежды на React + Vite: каталог с фильтрами, корзина, вход в аккаунт, бот-помощник с ответами на частые вопросы. Вёрстка адаптирована под телефон.

## Запуск

```
npm install
npm run dev
```

В PowerShell с отключёнными скриптами используйте `npm.cmd` вместо `npm`.

## Ограничения

- Вход демонстрационный: аккаунт и корзина хранятся в `localStorage` браузера, сервера нет.
- Оформление заказа и подписка не отправляют данные.
- Ответы бота задаются списком `faq` в `src/Bot.jsx`.
